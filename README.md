# 🏆 Trofy Landing Page

A premium, dark-themed landing page for **Trofy** built with **Nuxt 4**.

## ✨ Features
- **Modern Design**: Inspired by Laurel/Cruip aesthetics.
- **Glassmorphism**: Elegant blur effects and borders.
- **Responsive**: Fully optimized for mobile and desktop.
- **Scroll Animations**: Smooth entry effects using Intersection Observer.
- **Vanilla CSS**: Clean, fast, and no external dependencies.

## 🚀 Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run development server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```

## 🎨 Design System
- **Background**: `#050508`
- **Primary**: `#7c5cfc` (Purple)
- **Accent**: `#ff3e83` (Pink)
- **Typography**: Inter & Outfit (Google Fonts)
